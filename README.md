# .github

Default community-health files for every [whybothercoding](https://github.com/whybothercoding) repo that doesn't have its own — `CONTRIBUTING.md`, `SECURITY.md`, issue templates, and a PR template. GitHub automatically falls back to these when a repo is missing its own copy; a repo with its own file uses that one instead.

See [GitHub's docs on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file-for-your-organization) for how the fallback works.
