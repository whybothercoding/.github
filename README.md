# .github

This repository holds the organization-level profile and default community-health files for the [whybothercoding](https://github.com/whybothercoding) GitHub organization.

## Organization Profile

The organization's public profile is generated from `profile/README.md`. It showcases Theo's public work, including:
- **n8n Community Nodes** (`n8n-nodes-beehiiv`)
- **Self-Hosted Automation Stacks** (`self-hosted-automation-stack`)
- **MCP Servers** (`outscraper-mcp-server`)
- **Production-ready workflows and utilities**

## Community Health Fallbacks

This repository also stores the default community-health files that apply to any `whybothercoding` repository that doesn't define its own. GitHub automatically falls back to these files when a repo is missing its own copy. 

- `CONTRIBUTING.md`
- `SECURITY.md`
- `PULL_REQUEST_TEMPLATE.md`
- Issue templates

See [GitHub's docs on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file-for-your-organization) for how the fallback works.
